Issues requiring action before push
1. ConversationStore.close() is a no-op — database handle leaked

_db is declared but never assigned in _open(), so close() always calls null?.close(). The database handle is never closed. Fix is one line in _open():


// current
return _factory.openDatabase(path, options: ...);

// fix
return _db = await _factory.openDatabase(path, options: ...);
2. flutter_secure_storage is in pubspec.yaml but unused

The spec originally required it for token storage, but the deliberate decision was to let google_sign_in 7.x manage its own tokens. Nothing in the codebase imports it. Remove it from pubspec.yaml (and re-run flutter pub get to update pubspec.lock) — a dead dependency will confuse future readers and inflates the APK.
